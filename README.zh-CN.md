## 🧰 [grab-series-vocab](https://github.com/bannysway/grab-series-vocab)

一个 **agent 技能**，同时也是命令行工具，装在同一个文件夹里。指向任意一个字幕目录，它就能建出一个可检索的词汇库——词头、释义、音标、难度——并导出为 Anki、Markdown 或单文件网页。

它来自一次测量。我当时是**一集一集**做的词汇卡，等把 33,270 张卡合起来，才发现**其中 35.9% 是重复的**：`pick up` 被独立选中了 39 次，`check out` 35 次，`take off` 33 次。重复不只是白做工——一个词三份卡片就是三倍的复习量，而间隔重复算法是在对着错误的数据做优化。

解法不是把提示词写好一点，而是换一个数据结构：**先把语料库建起来，把每一次导出都当成对它的一个视图。**

合计：**402 集**、22,477 张收集到的卡、**14,413 个去重词头**。

每个语料库都是独立的。下载、导入 Anki、开始学就行——不需要装工具。三个库各自的词头加起来是 15,867，但真正的唯一数是 14,413：有 1,314 个词跨剧重复出现。没有人会手动去选两遍——而这正是这个工具要防的重复。所以库是按词头全局去重的，不是按集。

## 怎么用它们学

1. **取库**——选一部你本来就会看的剧，按季集顺序拿下来。
2. **在情境里刷**——每条词条都记着它出自第几季第几集，所以你知道这个词是在*哪儿*遇到的，而不只是它什么意思。
3. **关字幕看原剧**——每刷完四到五集，就去看这几集的无字幕版。干活的是这一步。
4. **回库检索**——没记住的，丢进自己的难点牌组。

间隔重复擅长让你**记住**；剧集告诉你**什么时候用它**。

## 装这个技能

```bash
npx skills add bannysway/grab-series-vocab --skill grab-series-vocab
```

它就是一个普通的 `SKILL.md` 文件夹，所以凡是实现了 Agent Skills 标准的地方都能用——Claude Code、Codex CLI、WorkBuddy、Cursor、Gemini CLI。各家路径见[安装指南](https://github.com/bannysway/grab-series-vocab/blob/main/docs/INSTALL.md)。

## 任何地方都没有字幕原文

这里的仓库不含字幕文件、不含转录稿、也不含台词翻译。公开的每一条都是词头、释义和音标——没有别的。这一点靠**脚本来保证**，不靠自觉：发布审计一旦发现违反就直接让构建失败。
